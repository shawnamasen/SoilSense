# SoilSense web platform

This folder contains the SoilSense web frontend and optional backend service.

- `frontend/` – public landing page and admin portal built with React + Vite
- `backend/` – optional Node.js API service

Use the repository root [`README.md`](../README.md) for the project overview and [`docs/SETUP.md`](../docs/SETUP.md) for setup, build, and deployment instructions.
